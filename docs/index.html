Supreme Council

A Windows desktop app for gathering and comparing answers from eligible free AI models.

Release downloads Documentation

What it does

  • Ranks eligible models by task fit, reliability and diversity.
  • Replaces failures within shared request and token budgets.
  • Saves individual responses and a report, even when synthesis fails.

Install on Windows

  1. Install Python 3.10 or newer with Tcl/Tk and the Windows launcher.
  2. Extract the Windows ZIP and run SETUP_COUNCIL.bat.
  3. Configure local provider credentials and approvals, then run START_COUNCIL.bat.

Privacy and free-tier use

Credentials stay on your computer. Cloud submissions require consent and free-tier providers may retain submitted text. Confidential mode blocks cloud execution.
